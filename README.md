# Portfolio

Personal portfolio for a software developer, built with Next.js App Router, TypeScript, and Tailwind CSS.

## Scripts

```bash
npm run dev
npm run lint
npm run build
npx tsc --noEmit
```

## Content

All personal content lives in `data/`. Placeholder copy is marked with `TODO: replace`.

## Environment

Copy `.env.example` to `.env.local` and fill in the Resend values:

```bash
RESEND_API_KEY=
CONTACT_TO_EMAIL=
CONTACT_FROM_EMAIL=
```

Never commit `.env.local`.
